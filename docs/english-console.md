### 상세 설명

```
해외여행이나 일상에서 바로 쓰는 영어 한 문장을 하루에 하나씩 배워요.
처음 화면에서 오늘의 문장과 쓰는 상황을 보고 '뜻 보고 배우기'를 누르면, 한글로 적은 발음과 뜻, 상대가 흔히 하는 대답까지 큰 글씨로 볼 수 있어요.
듣기 버튼을 누르면 영어 발음을 들려주고, 한 번 더 누르면 더 천천히 읽어 줘요.
다 읽고 나면 퀴즈 3문제를 풀어요. 뜻 맞히기, 상황에 맞는 문장 고르기, 빈칸 단어 채우기로 오늘 배운 표현을 확인해요.
퀴즈를 마치면 여권 도장을 찍어 주고, 며칠째 이어서 배우는지 알려드려요.
지난 기록에서는 도장 찍은 날을 달력으로 보고, 틀린 표현만 모아 다시 볼 수 있어요.
```

### 출시 노트 (첫 버전)

```
여행·생활 영어 한 문장을 매일 배우는 학습 앱입니다. 첫 화면에서 오늘의 문장을 보고 '뜻 보고 배우기'를 누르면 한글 발음·뜻·대화 예시를 읽고 듣기 버튼으로 발음을 들은 뒤 퀴즈 3문제를 풉니다. 결과 화면에서 출석 도장과 연속 학습일을 보여주고, 원하는 사용자만 리워드 광고를 보고 복습 문제를 더 풀 수 있습니다. 하단 '지난 기록'에서 출석 달력과 틀린 표현 복습을 볼 수 있습니다. 듣기는 기기에 내장된 음성 기능을 사용하며 별도 권한이 필요하지 않습니다.
```

## 3. 푸시 알림 (출시 후, 사자성어와 같은 방식)

- 알림동의문 이름: 오늘의 영어 한마디 도착 알림 동의문 / 발송 시점: `1. 매일 오전 8시, 오늘의 새 영어 한마디가 도착했을 때`
- 캠페인: 토스에게 발송 요청하기 · 제목 `영어 한마디` · 내용 `오늘의 영어 한마디가 도착했어요.` · 발송 코드 `daily` → `daily-english-hanmadi-daily`
- 정기 발송 · 매일 · 08:00 · 종료일 없음, 시작일은 알림 동의 업데이트 승인 이후
