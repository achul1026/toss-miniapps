### 상세 설명

```
되요와 돼요, 웬일과 왠일처럼 매번 헷갈리는 맞춤법을 하루에 하나씩 바로잡아요.
처음 화면에서 오늘의 두 표기 중 어느 쪽이 맞는지 생각해 보고 '정답 보고 배우기'를 누르면, 바른 표기와 예문, 왜 그런지, 쉽게 구별하는 요령을 큰 글씨로 볼 수 있어요.
다 읽고 나면 퀴즈 3문제를 풀어요. 빈칸 채우기, 바르게 쓴 문장 고르기, 맞춤법이 바른 말 고르기로 오늘 배운 내용을 확인해요.
퀴즈를 마치면 '참 잘했어요' 도장을 받고, 며칠째 이어서 배우는지 알려드려요.
지난 기록에서는 도장 받은 날을 달력으로 보고, 틀린 맞춤법만 모아 다시 볼 수 있어요.
```

### 출시 노트 (첫 버전)

```
매일 헷갈리는 맞춤법 하나를 배우는 학습 앱입니다. 첫 화면에서 오늘의 두 표기를 보고 '정답 보고 배우기'를 누르면 바른 표기·예문·이유·구별 요령을 읽은 뒤 퀴즈 3문제를 풉니다. 결과 화면에서 출석 도장과 연속 학습일을 보여주고, 원하는 사용자만 리워드 광고를 보고 복습 문제를 더 풀 수 있습니다. 하단 '지난 기록'에서 출석 달력과 틀린 문제 복습을 볼 수 있습니다.
```

## 3. 푸시 알림 (출시 후, 사자성어와 같은 방식)

- 알림동의문 이름: 오늘의 맞춤법 도착 알림 동의문 / 발송 시점: `1. 매일 오전 8시, 오늘의 새 맞춤법이 도착했을 때`
- 캠페인: 토스에게 발송 요청하기 · 제목 `맞춤법 도착` · 내용 `오늘의 맞춤법이 도착했어요.` · 발송 코드 `daily` → `daily-matchum-daily`
- 정기 발송 · 매일 · 08:00 · 종료일 없음, 시작일은 알림 동의 업데이트 승인 이후
- 발송 코드를 `.env.production`의 `VITE_PUSH_TEMPLATE_CODE`에 넣고 다시 빌드한다(비워 두면 알림 제안 카드가 보이지 않음).
