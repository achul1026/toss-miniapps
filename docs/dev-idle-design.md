# SI 개발자 키우기 — 게임 기획 (작업 기준 문서)

경철님이 세부 기능 기획을 맡겨서, 아래 순서와 규칙으로 만든다. 숫자는 `packages/dev-idle-core`와 `apps/dev-idle/src/events.ts`가 기준.

## 핵심 루프
사무실을 탭해 코딩 → 진척률 100%면 납품·용역비 → 팀원·장비 구매 → 승진 → 성장이 느려지면 이직(경력 +, 생산 +10%/년).

## 사무실 이벤트 (구현됨)
신입(납품 3건)부터, 화면이 켜져 있을 때만 2~4분마다 하나.

| 이벤트 | 확률 | 플레이 | 성공 | 실패·거절 |
| --- | --- | --- | --- | --- |
| 장애 발생 | 35% | 바닥의 버그 4마리를 15초 안에 탭. 모니터가 빨간 에러 화면, 서버 랙 경고등 | 지금 프로젝트 보상의 60% | 20초 동안 생산 ×0.5 |
| 감리 지적 | 25% | 책상 위 분홍 포스트잇 3장을 15초 안에 탭 | 보상의 80% | 보상 없음 |
| 야근 제안 | 25% | 수락/칼퇴 선택 | 60초 동안 생산 ×2, 사무실이 밤으로 | 없음 |
| 요구사항 변경 | 15% | 수락/거절 선택 | 진척 −30%, 보상의 60% 즉시 | 없음 |

## 다음 작업 순서
1. **광고·결제** — 보상형: 야근 효과 2배(×4), 자리 비운 동안 수익 2배, 장애 재도전. 결제: 광고 제거, 스타터 팩, 영구 생산 2배. 전면 광고는 쓰지 않는다.
2. **처음 하는 사람 안내** — 첫 탭, 첫 채용, 첫 납품까지 3단계 말풍선.
3. **소리** — 키보드, 납품, 버그 잡기. 끄기 버튼, 백그라운드에서 정지(출시 체크리스트).
4. **사무실 확장** — 직급이 오르면 사무실이 넓어지고(책상 8 → 12), 인테리어가 바뀜.
5. **게임 등급 표시와 출시 준비** — 등급분류 결과를 접속 화면에 표시, 콘솔용 썸네일(1932×828).
6. **리더보드** — 토스 게임 센터에 '최고 직급까지 걸린 시간' 또는 '누적 경력'.
