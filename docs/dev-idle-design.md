# SI 개발자 키우기 — 게임 기획 (작업 기준 문서)

경철님이 세부 기능 기획을 맡겨서, 아래 순서와 규칙으로 만든다. 숫자는 `packages/dev-idle-core`와 `apps/dev-idle/src/events.ts`가 기준.

## 핵심 루프
사무실을 탭해 코딩 → 진척률 100%면 납품·용역비 → 팀원·장비 구매 → 승진 → 성장이 느려지면 이직(경력 +, 생산 +10%/년).

## 사무실 이벤트 (구현됨)
신입(납품 3건)부터, 화면이 켜져 있을 때만 2~4분마다 하나.

| 이벤트 | 확률 | 플레이 | 성공 | 실패·거절 |
| --- | --- | --- | --- | --- |
| 장애 발생 | 35% | 바닥의 버그 4마리를 15초 안에 탭. 모니터가 빨간 에러 화면, 서버 랙 경고등 | 지금 프로젝트 보상의 60% | 20초 동안 생산 ×0.5 |
| 감리 지적 | 25% | 책상 위 분홍 포스트잇 3장을 15초 안에 탭 | 보상의 80% | 보상 없음 |
| 야근 제안 | 25% | 수락/칼퇴 선택 | 60초 동안 생산 ×2, 사무실이 밤으로 | 없음 |
| 요구사항 변경 | 15% | 수락/거절 선택 | 진척 −30%, 보상의 60% 즉시 | 없음 |

## 다음 작업 순서
1. **광고·결제** — 보상형: 야근 효과 2배(×4), 자리 비운 동안 수익 2배, 장애 재도전. 결제: 광고 제거, 스타터 팩, 영구 생산 2배. 전면 광고는 쓰지 않는다.
2. **처음 하는 사람 안내** — 첫 탭, 첫 채용, 첫 납품까지 3단계 말풍선.
3. **소리** — 키보드, 납품, 버그 잡기. 끄기 버튼, 백그라운드에서 정지(출시 체크리스트).
4. **사무실 확장** — 직급이 오르면 사무실이 넓어지고(책상 8 → 12), 인테리어가 바뀜.
5. **게임 등급 표시와 출시 준비** — 등급분류 결과를 접속 화면에 표시, 콘솔용 썸네일(1932×828).
6. **리더보드** — 토스 게임 센터에 '최고 직급까지 걸린 시간' 또는 '누적 경력'.

## 수익화 (구현됨)
전면 광고는 쓰지 않는다. 광고는 전부 플레이어가 고르는 보상형.

| 종류 | 어디서 | 효과 |
| --- | --- | --- |
| 보상형 광고 | 자리 비운 동안 카드 | 오프라인 수익 한 번 더 (2배) |
| 보상형 광고 | 야근 제안 | 60초 생산 ×4 (기본 ×2) |
| 인앱 결제 `dev_idle_starter` (소모성) | 상점 | 지금 단계 프로젝트 10건분 용역비 |
| 인앱 결제 `dev_idle_macbook` (비소모성) | 상점 | 생산 영구 ×2, 이직해도 유지, 환불 시 회수 |

콘솔 설정: 인앱 결제에 위 SKU 두 개를 등록하고, 인앱 광고에 리워드 광고 그룹을 만들어 `VITE_AD_REWARDED_ID`에 넣는다.
지급 안전장치: 같은 주문 번호는 한 번만 지급, 지급 전에 앱이 꺼진 주문은 다음 실행 때 다시 지급, 맥북은 실행할 때마다 구매·환불 내역으로 복원.

## 처음 안내와 효과음 (구현됨)
- 안내 말풍선은 포스트잇 모양으로 화면 흐름 안에 넣는다(가리는 팝업 없음). 순서: 사무실 누르기 → 첫 채용 → 조는 팀원 깨우기 → 장비 → 이직.
- 할 일을 하면 저절로 사라지고 "알겠어요"로 넘길 수 있다. 본 안내는 저장해서 다시 안 보인다. 이벤트·자리 비운 카드가 떠 있을 땐 숨긴다.
- 효과음은 Web Audio로 만든 짧은 8비트 소리(파일 없음): 키보드, 납품, 구매, 승진, 이벤트, 버그 잡기.
- 머리글 스피커 버튼으로 끄고 켜며 기기에 기억한다. 앱이 뒤로 가면 소리를 멈춘다.

## 사무실 이사 (구현됨)
직급이 오르면 더 좋은 곳으로 이사한다. 바닥·벽·책상·소파 색과 소품이 바뀌고, 사무실 아래에 지금 있는 곳 이름이 보인다.

| 직급 | 사무실 | 특징 |
| --- | --- | --- |
| 인턴·신입 | 반지하 사무실 | 콘크리트 바닥, 천장 쪽 작은 창, 철제 책상, 낡은 갈색 소파, 박스 더미 |
| 주니어·시니어 | 상가 2층 사무실 | 나무 바닥, 창 세 개, 화이트보드 |
| PL·PM | 강남 빌딩 12층 | 카펫 타일, 호두나무 책상, 감사패, 화분 둘 |
| 리드 아키텍트·CTO | 판교 사옥 꼭대기 층 | 통유리 너머 도시(밤엔 불 켜진 빌딩), 대시보드 TV, 흰 책상, 초록 라운지 소파 |

이사할 때는 승진 알림에 "사무실을 ○○(으)로 옮겼어요"를 덧붙인다.

## 리더보드 (구현됨)
토스 게임센터 리더보드 하나. 점수는 이직 포함 누적 납품 프로젝트 수라서 오래 즐긴 사람이 위로 간다.
예전 저장본은 지금 회사의 납품 수로 시작하고, 자리를 비운 동안 납품한 것도 더한다.
