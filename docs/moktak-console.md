# 마음 목탁 — 앱인토스 콘솔 설정

점수·순위·레벨이 없는 "기록 앱"이라 게임이 아닌 앱으로 등록한다(등급분류 필요 없음). 이 원칙을 지키려면 이후에도 순위나 레벨을 넣지 않는다.

## 1. 앱 등록 (게임 아님)

### 상세 설명

```
걱정이 많거나 마음이 어지러울 때, 목탁을 두드리며 잠시 쉬어 가세요.
화면의 목탁을 누르면 맑은 목탁 소리와 함께 '공덕 +1'이 떠올라요. 떠오르는 말은 행운, 건강, 평안이나 '걱정 -1'처럼 바꿀 수 있고, 직접 쓸 수도 있어요.
염주 모드에서는 염주 알을 한 알씩 넘기며 108알 한 바퀴를 돌아요.
하루 108번을 채우면 인장이 찍히고, 며칠째 이어서 마음을 다스리고 있는지 알려드려요.
지난 기록에서는 오늘 두드린 횟수, 지금까지 모은 횟수, 염주 바퀴 수와 108번을 채운 날을 달력으로 볼 수 있어요.
소리와 진동은 위쪽 버튼으로 끄고 켤 수 있어요.
```

### 출시 노트 (첫 버전)

```
목탁을 두드리거나 염주를 넘기며 마음을 다스리는 기록 앱입니다. 첫 화면의 목탁을 누르면 소리·진동과 함께 '공덕 +1' 같은 문구가 떠오르고 오늘 횟수가 올라갑니다. 위쪽에서 목탁/염주 모드와 소리·진동을 바꿀 수 있고, 아래 '떠오르는 말'에서 문구를 고르거나 직접 쓸 수 있습니다. 하루 108번을 채우면 기록이 남고, 원하는 사용자만 리워드 광고를 보고 10분 동안 자동으로 두드리는 기능을 쓸 수 있습니다. '지난 기록 보기'에서 누적 횟수와 달력을 봅니다. 점수·순위·레벨은 없습니다.
```

## 2. 인앱 광고

## 3. 푸시 알림 (출시 후)

- 알림동의문 이름: 마음 목탁 아침 알림 동의문 / 발송 시점: `1. 매일 오전 8시, 오늘의 108번을 시작하라고 알려드릴 때`
- 캠페인: 토스에게 발송 요청하기 · 제목 `마음 목탁` · 내용 `오늘의 108번을 시작해 보세요.` · 발송 코드 `daily` → `maeum-moktak-daily`
- 정기 발송 · 매일 · 08:00 · 종료일 없음
- 동의 카드는 하루 108번을 처음 채웠을 때 한 번만 보인다.
